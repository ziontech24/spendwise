# SpendWise

**Your money. Your budget. Your peace of mind.**

SpendWise is a personalized and interactive personal finance web application designed to help me manage my income, expenses, budgets, savings, and financial commitments.

The application aims to make personal money management easier through:

- Income and expense tracking
- Personalized daily spending recommendations
- Monthly and category-based budgeting
- Tracking money I owe and money others owe me
- Repayment reminders
- Personalized greetings and daily financial updates
- Interactive financial summaries

SpendWise is being developed as a personal project to solve everyday financial management problems while exploring frontend development, backend development, database design, and practical software engineering.
